# Dose — Claude Code starter package

1. Unzip somewhere, e.g. `~/Projects/dose-app`
2. `cd ~/Projects/dose-app && claude`
3. Paste the contents of `PROMPT.md` as your first message.

Contents
- `PROMPT.md` — the one-shot build prompt
- `CLAUDE.md` — project rules Claude Code loads automatically
- `docs/calculator-spec.md` — formulas, modes and test cases
- `docs/design-spec.md` — visual system mapped to the reference images
- `reference/` — the 5 design references
